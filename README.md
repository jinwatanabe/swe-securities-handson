# 注文管理アプリ（セキュアコーディング研修 教材）

新人エンジニア研修で「現場でやりがちな実装ミス」を観察し、安全な実装に直す練習をするためのサンプルアプリです。
シンプルな注文管理アプリとして、ユーザー登録・ログイン、注文の一覧／作成／キャンセル、プロフィール編集、
管理者向けの全注文・ユーザー管理画面を備えています。

> この教材は **完全にローカルの Docker 内で完結** します。外部ネットワークや実在サービスには一切アクセスしません。

## 構成

| サービス | 役割 | ポート |
|---|---|---|
| frontend | React + TypeScript (Vite) | http://localhost:5173 |
| backend | Hono + TypeScript (@hono/node-server) | http://localhost:3000 |
| db | PostgreSQL 16 | （コンテナ内のみ） |
| internal | 社内ネットワーク上の別サービスを模した内部サービス | （コンテナ内のみ） |

## 起動方法

```bash
docker compose up --build
```

- フロント・API・DB・初期データ投入まで自動で完了します。
- 起動後、ブラウザで http://localhost:5173 を開いてください。
- 停止・データ初期化は `docker compose down -v` です。

## 初期ユーザー

| 役割 | メールアドレス | パスワード |
|---|---|---|
| 一般ユーザー | alice@example.com | alice123 |
| 一般ユーザー | bob@example.com | bob123 |
| 管理者 | admin@example.com | admin123 |

各ユーザーには、研修中に挙動を確認するためのサンプル注文があらかじめ入っています。

## 画面の説明

- **ログイン／登録**：メールアドレスとパスワードでログイン、または新規登録します。
- **注文**：自分の注文の一覧・検索・新規作成・キャンセル・詳細表示ができます。
- **プロフィール**：名前・電話番号・アバター画像URLを編集できます。URLはプレビュー表示できます。
- **管理**（管理者のみ表示）：全ユーザーの一覧とロール変更、全注文の一覧ができます。

## API 概要

| メソッド | パス | 説明 |
|---|---|---|
| POST | `/api/auth/register` | ユーザー登録 |
| POST | `/api/auth/login` | ログイン |
| GET | `/api/orders` | 自分の注文一覧 |
| GET | `/api/orders/search?q=` | 注文検索 |
| GET | `/api/orders/:id` | 注文詳細 |
| POST | `/api/orders` | 注文作成 |
| POST | `/api/orders/:id/cancel` | 注文キャンセル |
| GET | `/api/profile` | プロフィール取得 |
| PUT | `/api/profile` | プロフィール更新 |
| POST | `/api/profile/avatar/preview` | アバターURLのプレビュー取得 |
| GET | `/api/admin/orders` | 全注文一覧 |
| GET | `/api/admin/users` | 全ユーザー一覧 |
| PATCH | `/api/admin/users/:id/role` | ユーザーのロール変更 |

## 研修の進め方

1. まずアプリを一通り触って、どんな機能があるか把握します。
2. 各機能のリクエスト／レスポンスを観察し、「この実装で問題はないか？」を自分で考えます。
3. 気づいた点をメモしたうえで、講師用資料と答え合わせをします。
4. 問題のある実装を、安全な書き方に直してみます。

> 認証トークンやAPIの挙動は、ブラウザの開発者ツール（Network タブ）や `curl` で確認できます。
